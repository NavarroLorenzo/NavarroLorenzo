# Hola, soy Lorenzo Navarro

Estudio Ingeniería en Sistemas en la Universidad Católica de Córdoba. Me interesan la ciencia de datos, la ingeniería de datos y el desarrollo de sistemas que ayuden a entender y usar mejor la información.

En mis proyectos trabajé con **Go, Python, C++, React y TypeScript**. También usé **PostgreSQL, MySQL y MongoDB**, tanto para consultas como para modelado y mantenimiento de datos. Estoy profundizando en análisis de datos y tengo conocimientos iniciales de **Power BI**.
